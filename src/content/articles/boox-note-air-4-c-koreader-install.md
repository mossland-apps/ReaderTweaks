steps:
  - instruction: Install KOReader
    detail: >-
      Open the Play Store, search for "KOReader", and install it. If you prefer
      not to use Google, download the "koreader-android" APK from the KOReader
      releases page in the device's browser and open it to install; allow
      "install unknown apps" for the browser when prompted.
  - instruction: Open KOReader and grant file access
    detail: >-
      Launch KOReader. On first run it asks for permission to access storage —
      grant it, and if Android shows an "all files access" toggle for KOReader,
      turn that on too. Without it, KOReader cannot see books outside its own
      folder.
  - instruction: Point KOReader at your books folder
    detail: >-
      In KOReader, open the file browser (top-left menu) and navigate to where
      your books are — "Books" or "Download" in internal storage, or the microSD
      card. Long-press a folder and "Set as home directory".
  - instruction: Set KOReader's BOOX refresh mode
    detail: >-
      Leave KOReader, open its BOOX optimisation panel, set its refresh mode to
      HD or Regal, and set it to black-and-white — colour adds nothing for plain
      text and softens it. Turn off any BOOX "app-level full refresh" — KOReader
      manages its own.
  - instruction: Set KOReader's own refresh inside the app
    detail: >-
      Back in KOReader, open the top menu, then the gear, then "Screen", and set
      "full refresh every N pages" (every 1 page is cleanest, every 6 is a
      compromise). This is the setting to use, not BOOX's.
  - instruction: Optional — tune gestures for the big screen
    detail: >-
      In KOReader's "Taps and gestures", widen the page-turn tap zones and set a
      multi-swipe or corner gesture for the table of contents, since your thumb
      does not reach the far edge of a 10.3-inch screen one-handed.
---

On the Note Air 4 C, KOReader installs like any Android app — from the Play
Store or an APK, no jailbreak. The two things that make it look right are
granting full file access so it can find your books, and letting KOReader manage
e-ink refresh itself in black-and-white rather than through BOOX's per-app
colour system. Keep NeoReader or BOOX Notes for anything involving the pen.
