steps:
  - instruction: Install KOReader
    detail: >-
      KOReader is not on the Google Play Store, so ignore look-alike listings
      there. Either install the F-Droid app store and get KOReader from it, or
      download the "koreader-android-arm" APK from the KOReader releases page on
      GitHub in the device's browser and open it to install. You may need to
      allow "install unknown apps" for the browser or F-Droid when prompted.
  - instruction: Open KOReader and grant file access
    detail: >-
      Launch KOReader. On first run it asks for permission to access storage —
      grant it, and if Android shows an "all files access" toggle for KOReader,
      turn that on too.
  - instruction: Point KOReader at your books folder
    detail: >-
      In KOReader, open the file browser (top-left menu) and navigate to where
      your books are — "Books" or "Download" in internal storage, or the microSD
      card. Long-press a folder and "Set as home directory".
  - instruction: Set KOReader's BOOX refresh mode
    detail: >-
      Leave KOReader, open its BOOX optimisation panel, and set its refresh mode
      to HD or Regal. Turn off any BOOX "app-level full refresh" setting —
      KOReader manages its own.
  - instruction: Set KOReader's own refresh inside the app
    detail: >-
      Back in KOReader, open the top menu, then the gear, then "Screen", and set
      "full refresh every N pages" (every 1 page is cleanest, every 6 is a
      compromise).
  - instruction: Map the volume keys and tune the gestures
    detail: >-
      In KOReader's "Taps and gestures", then "Physical buttons", map the Palma
      2's volume keys to next and previous page. Because it is a one-handed
      device, also check the tap zones and edge swipes are reachable with your
      thumb.
---

On the Palma 2, KOReader installs like any Android app — no jailbreak. Grant full
file access so it can find your books, let KOReader manage e-ink refresh itself,
and map the volume rocker to page turns inside KOReader so you can read
one-handed the way you would in the stock reader.
