steps:
  - instruction: Decide which apps you actually need
    detail: >-
      The Go 6 can run all of them, but each app you sign into is another account
      and another thing syncing. Common picks are the Kindle app for Amazon
      purchases, the Kobo app for Kobo store and library books, Libby for public
      library loans, and a general reader such as Moon+ Reader or ReadEra for
      your own files. KOReader has its own section.
  - instruction: Install from the Play Store
    detail: >-
      Open the Play Store, search for the app, and install it as you would on a
      phone. If an app is missing from search, try the Play Store website in the
      device's browser, or sideload the APK from a trusted source such as the
      developer's site.
  - instruction: Open the app once, then open BOOX's per-app settings
    detail: >-
      Launch the app so Android registers it. Then go to the Apps screen, find
      the app, and open its BOOX "optimisation" panel — a long-press option, or
      Settings, then "App optimisation". This dialog is where you fix how the app
      looks and behaves.
  - instruction: Set the display and refresh options per app
    detail: >-
      For a text reading app choose a clean refresh mode (Regal or Normal), turn
      on "bleach" or "enhance contrast" only if text looks grey, and enable "full
      refresh on page turn" if you see heavy ghosting. On the small 6-inch screen
      the DPI slider is also worth checking so phone-sized apps are not cramped.
  - instruction: Control background behaviour
    detail: >-
      Under Settings, then "Power", set reading apps you only open occasionally to
      be "optimised" or allowed to be closed in the background, so they do not
      drain the battery syncing. Keep an app you use constantly exempt so it
      resumes instantly.
  - instruction: Turn off in-app animations and effects
    detail: >-
      In each app's own settings, turn off page-turn animations, "curl" effects
      and auto-brightness — they look bad and stutter on e-ink. Set the app's own
      theme to a plain light mode.
---

The Go 6's strength is that it runs the real Kindle, Kobo, Libby and other apps,
so you are not locked to one store. The price is that each app needs two rounds
of setup: the app's own account and settings, and BOOX's per-app optimisation
panel that controls refresh and background behaviour. On the small screen, spend
a moment on each app's DPI as well so the layout is not phone-sized.
