  - instruction: Install KOReader
    detail: >-
      Open the Play Store, search for "KOReader", and install it. If you prefer
      not to use Google, download the "koreader-android" APK from the KOReader
      releases page in the device's browser and open it to install; you may need
      to allow "install unknown apps" for the browser when prompted.
  - instruction: Open KOReader and grant file access
    detail: >-
      Launch KOReader. On first run it asks for permission to access storage —
      grant it, and if Android shows an "all files access" toggle for KOReader,
      turn that on too. Without it, KOReader cannot see books outside its own
      folder.
  - instruction: Point KOReader at your books folder
    detail: >-
      In KOReader, open the file browser (top-left menu) and navigate to where
      your books are — often "Books" or "Download" in internal storage, or the
      microSD card. Long-press a folder and "Set as home directory" so it opens
      there each time.
  - instruction: Set KOReader's BOOX refresh mode
    detail: >-
      Leave KOReader, go to the Apps screen, open KOReader's BOOX optimisation
      panel, and set its refresh mode to HD or Regal. Turn off any BOOX
      "app-level full refresh" setting — KOReader does its own refresh management
      and the two fighting each other causes flicker.
  - instruction: Set KOReader's own refresh inside the app
    detail: >-
      Back in KOReader, open the top menu, then the gear, then "Screen", and set
      "full refresh every N pages" to your taste (every 1 page is cleanest, every
      6 is a good compromise). This is the setting to use, not BOOX's.
  - instruction: Optional — map the physical buttons
    detail: >-
      In KOReader's menu under "Taps and gestures", then "Physical buttons", you
      can assign the Go Color 7's two page-turn buttons to next and previous
      page, and set long-press actions.

On the Go Color 7, KOReader installs like any Android app — from the Play Store
or an APK, with no jailbreak. The two things that make it look right are granting
full file access so it can find your books, and letting KOReader manage e-ink
refresh itself rather than BOOX's per-app system. Once that is set, KOReader on a
BOOX is one of the cleanest reading experiences available.
