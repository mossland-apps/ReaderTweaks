steps:
  - instruction: Pick a template when you create a notebook
    detail: >-
      In BOOX Notes, tap to make a new notebook. Before you confirm, choose a
      template — Blank, several line and dot spacings, grids, Cornell notes,
      weekly and daily planners, to-do lists, music staves and more.
  - instruction: Change the template for the whole notebook
    detail: >-
      Open a notebook, open the notebook or page menu, and choose "Template".
      Applying it at notebook level changes every page still using the old one.
  - instruction: Use a different template on a single page
    detail: >-
      On the page you want to change, open the page menu and set the template
      just for that page. One notebook can mix a planner page with free-form note
      pages.
  - instruction: Add your own template from an image or PDF
    detail: >-
      Unlike a Kindle Scribe, BOOX lets you load a custom template. Put a PNG or
      PDF page in the templates folder (or import it from the template picker),
      and it appears as a choice. This is how you get a company form, a habit
      tracker or a specific planner layout.
  - instruction: Or write directly on a PDF instead
    detail: >-
      If you want to fill in an existing document rather than reproduce its
      layout, open the PDF in NeoReader and write on it there. The markup saves
      with the PDF and exports from the share menu.
  - instruction: Set a default for new notebooks
    detail: >-
      In BOOX Notes settings, set the template a new notebook starts with so you
      are not choosing every time.
---

Templates on the Note Air 4 C are more flexible than on a closed device: the
built-in set is large, they apply per notebook or per page, and you can add your
own from a PNG or PDF. If you just need to annotate an existing form, writing
straight on the PDF in NeoReader is simpler than turning it into a template.
