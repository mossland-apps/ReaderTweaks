steps:
  - instruction: Pick a template when you create a notebook
    detail: >-
      From the Notebooks tab, tap the plus to make a new notebook. Before you
      confirm, choose a template from the picker — options include Blank, Lined
      (a few line spacings), Dotted, Grid, and productivity layouts such as
      Daily planner, Weekly planner, To-do and Meeting notes.
  - instruction: Change the template for the whole notebook
    detail: >-
      Open a notebook, open the page or notebook menu, and choose "Change
      template". Applying it here changes every page that is still using the old
      template.
  - instruction: Use a different template on a single page
    detail: >-
      On the page you want to change, open the page menu and choose the template
      just for that page. This lets one notebook mix, for example, a planner page
      followed by blank pages for notes.
  - instruction: Add pages with the same or a new template
    detail: >-
      The "add page" button adds a page using the current template. Hold it, on
      some firmware, to choose a different template for the new page.
  - instruction: Understand the limits
    detail: >-
      The template set is fixed. You cannot import a PDF as a template, draw your
      own and reuse it, or download template packs. If a specific planner layout
      matters to you, the workaround is to send that layout in as a PDF and write
      on it as a document instead of a notebook — you lose the notebook features
      but gain any layout you like.
---

Templates on the Scribe are a pick-from-a-list feature, not something you build.
The useful part is that templates apply per notebook or per page, so one
notebook can hold a weekly planner and free-form note pages together. If you
need a layout Amazon does not provide, sending it in as a PDF and marking that
up is the only route.
