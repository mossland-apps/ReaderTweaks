steps:
  - instruction: Open the optimisation dialog for an app
    detail: >-
      From the Apps screen, long-press an app and choose "Optimise" (or open the
      app, then swipe down for the control centre and tap the optimisation icon).
      A panel of sliders and toggles appears, applying only to that app.
  - instruction: Set the refresh mode
    detail: >-
      Choose the refresh mode for this app. Text readers get HD or Regal;
      browsers, comics and stores get Balanced or Fast. This overrides the global
      mode whenever the app is in front.
  - instruction: Set full refresh frequency
    detail: >-
      "Full refresh every N pages" or a similar toggle clears accumulated
      ghosting. Every 1 page is cleanest but flickers most; every 3 to 5 is a
      common compromise. For an app that already manages its own refresh
      (KOReader), turn this off.
  - instruction: Adjust contrast, bleach and sharpen
    detail: >-
      "Enhance contrast" or "bleach whites" fixes grey-looking text and faint UI.
      Use it sparingly — too much crushes thin fonts. "Sharpen" or "bold text"
      can help small type. Colour apps generally need less of this.
  - instruction: Change the app's DPI if the layout is cramped or huge
    detail: >-
      Some phone apps show a tiny phone-sized layout or an oversized one on the
      7-inch screen. The DPI slider rescales the app — nudge it until buttons and
      text are a comfortable size, then reopen the app to apply.
  - instruction: Filter animations
    detail: >-
      "Animation filter" or "disable animations" stops page-curl effects,
      fade-ins and spinners that stutter on e-ink. Turn it on for almost every
      reading and store app. Leave it off for a video or drawing app that needs
      motion.
  - instruction: Handle dark themes
    detail: >-
      If an app forces a dark theme you cannot change in its own settings, use
      the optimisation dialog's colour-invert or "force light" option so text is
      dark-on-light, which is what e-ink is made for.
---

The optimisation dialog is where a BOOX goes from "usable" to "good". Work
through it once per app you care about: pick a refresh mode, set full-refresh
frequency (off for KOReader, every few pages for others), nudge contrast only if
text is grey, fix the DPI if the layout is wrong, and filter animations. Ten
minutes per app, and you rarely touch it again.
