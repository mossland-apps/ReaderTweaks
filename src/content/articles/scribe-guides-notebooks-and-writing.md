steps:
  - instruction: Create a notebook
    detail: >-
      From the home screen, open the Notebooks tab and tap the plus to make a
      new notebook. Give it a name and pick a template — plain, lined, dotted,
      grid, planner and several others. You can change the template later, and
      different pages in one notebook can use different templates.
  - instruction: Learn the writing tools
    detail: >-
      The toolbar has pen, pencil, marker (highlighter), fountain pen and eraser,
      each with size options, plus an undo and redo. The lasso tool selects
      handwriting so you can move, resize, cut or copy it. On the Premium Pen the
      barrel button is a shortcut you can set to the eraser or the last tool.
  - instruction: Write notes directly on a book page
    detail: >-
      Open a book and start writing with the pen, or tap the pen icon in the
      reading toolbar. The Scribe adds a writing layer over the page — this is
      sometimes called Active Canvas. Your notes stay attached to that spot in
      the book and reflow with the text if you change the font size. You can also
      add a collapsible sticky note that does not cover the words.
  - instruction: Convert handwriting to text
    detail: >-
      In a notebook, open the page menu and choose "Convert to text", or select
      handwriting with the lasso and convert just that. The Scribe turns it into
      typed text you can then email or copy. Accuracy depends on how tidy the
      writing is; printing works better than fast cursive.
  - instruction: Export a notebook or notes
    detail: >-
      From a notebook's menu, choose Share, then email it as a PDF (the
      handwriting as-is) or as converted text. Book annotations can be exported
      the same way from the book's share menu. Export needs Wi-Fi and a
      registered account.
  - instruction: Know what does not work
    detail: >-
      You cannot add your own templates to the built-in set, import notes from
      another brand of tablet, or use the pen as a mouse in menus. Handwriting
      search inside notebooks is limited. And notebooks are tied to Amazon —
      there is no open file you can pull off by cable, only the PDF or text you
      export.
---

The Scribe's note-taking is genuinely good for meetings, margins and PDF markup,
and the handwriting-to-text conversion is usable if you print rather than
scrawl. The main limits are that everything lives inside Amazon's system —
export is by email as PDF or text, not an open file — and the template set is
fixed.
