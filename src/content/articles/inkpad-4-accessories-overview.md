The InkPad 4 is large and a bit heavier, so a case matters more than on a pocket
reader — both for protection and, with a fold-back folio, for propping it up
during long PDF sessions. Get one that sleeps and wakes the device and leaves
the bottom buttons clear. The InkPad 4 has a built-in speaker, so headphones are
optional, but a set of Bluetooth earbuds is worth having for private listening.
There is no microSD slot, so a card is not an option here. Picks are grouped by
type below, with a note on which are cut for this device and which fit any
reader.
