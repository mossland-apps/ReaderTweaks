PocketBook's software is more open than Kobo's or Amazon's: you can copy almost
any book file straight onto the device and it will open. This section covers
setting up a new Verse, the several ways to load books, and how to read
Adobe-DRM library loans without a computer. The
[Calibre](/devices/pocketbook/pocketbook-verse/calibre/) and
[KOReader](/devices/pocketbook/pocketbook-verse/koreader/) sections cover those;
[Customization](/devices/pocketbook/pocketbook-verse/customization/) covers
fonts, remapping the buttons and the sleep screen.

## Start here

- **[Set up a new PocketBook Verse](/devices/pocketbook/pocketbook-verse/guides/first-setup/)**
  — accounts, Wi-Fi, and the Adobe ID for library books.
- **[Get books onto the PocketBook Verse](/devices/pocketbook/pocketbook-verse/guides/get-books-on/)**
  — USB, the Send-to-PocketBook email service, microSD and cloud sync.
- **[Read library books on the PocketBook Verse](/devices/pocketbook/pocketbook-verse/guides/library-books/)**
  — Libby, Adobe DRM, and the ".acsm" file.
