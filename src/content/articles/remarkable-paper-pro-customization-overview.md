The stock reMarkable software is deliberately minimal. There are no third-party
apps, no font folder for reading, and no gesture editor. What you can change:

- **Templates.** Pick from a large built-in set per notebook and per page. With
  developer mode you can add your own custom templates.
- **Writing tools.** Set default pen, thickness and colour, and the Marker Plus
  shortcut button.
- **Reading and writing settings.** Handedness, palm rejection, the toolbar
  position, page-turn taps, and how PDFs fit the screen.
- **Tags and folders** for organising a library that fills up fast.

Deeper changes — custom fonts for reading, a different UI, KOReader — all go
through [developer mode](/devices/remarkable/remarkable-paper-pro/koreader/) and
the SSH access it provides.
