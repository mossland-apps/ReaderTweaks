The stock reMarkable software is deliberately minimal: no third-party apps, no
font folder for reading, no gesture editor. What you can change without going
further:

- **Templates.** Pick from a large built-in set per notebook and per page. With
  developer mode you can add your own custom templates.
- **Writing tools.** Set default pen, thickness and shade, and the Marker Plus
  shortcut button.
- **Reading and writing settings.** Handedness, palm rejection, the toolbar
  position, page-turn taps, and how PDFs fit the screen. There is no front light.
- **Tags and folders** for organising a library that fills up fast.

Because the reMarkable 2's developer mode has been stable for years, its
community-modification scene is the largest of any e-ink device: custom
templates, alternative launchers, screen-sharing, third-party sync clients,
custom sleep screens, and [KOReader](/devices/remarkable/remarkable-2/koreader/).
All of it goes through the SSH access developer mode provides.
