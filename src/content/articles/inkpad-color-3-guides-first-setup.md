steps:
  - instruction: Charge the InkPad Color 3 before setup
    detail: >-
      A new device often ships part-charged, and setup includes a firmware
      update. Plug it in with the supplied USB-C cable and give it 30 minutes or
      more before you start.
  - instruction: Turn it on and choose your language and keyboard
    detail: >-
      Press the power button on the top edge. PocketBook asks for the interface
      language and keyboard layout first; this does not limit what languages your
      books can be in.
  - instruction: Connect to Wi-Fi and install any firmware update
    detail: >-
      Choose your network and enter the password. If an update is offered,
      install it and let the device restart. PocketBook updates add format
      support and colour-rendering fixes, so it is worth doing now.
  - instruction: Decide about a PocketBook account
    detail: >-
      A PocketBook account is used for the PocketBook Cloud (syncing books and
      reading position across devices and apps), the book store, and the
      Send-to-PocketBook email service. It is not required to read files you copy
      on yourself. You can skip it during setup and add it later under Settings,
      then Accounts and Synchronization.
    tip: >-
      If you plan to sideload everything by cable or use KOReader, skip the
      account. Add it only if you want the email delivery or cloud sync.
  - instruction: "Optional: authorise an Adobe ID for library books"
    detail: >-
      The InkPad Color 3 can open EPUB and PDF books protected with Adobe DRM —
      the kind most public libraries lend — without a computer. To use that, go
      to Settings, then Accounts and Synchronization, then "Adobe DRM", and sign
      in with a free Adobe ID. Skip this if you only read your own unprotected
      files.
  - instruction: Learn the buttons, the SMARTlight and the colour toggle
    detail: >-
      Two buttons on the bottom bezel turn pages. Swipe down from the top for the
      SMARTlight controls — brightness and a separate warm-tone slider. There is
      also a quick way to switch the screen between colour and pure
      black-and-white; use black-and-white for plain novels, where it is sharper.
  - instruction: Set your expectations for the colour
    detail: >-
      Kaleido 3 colour is muted and lower-resolution than a phone or tablet — it
      looks like good newsprint, not a glossy magazine. The black-and-white text
      layer is the sharp 300-ppi one. The next guides cover getting the best out
      of both.
  - instruction: Add your books
    detail: >-
      Connect the InkPad Color 3 to a computer by USB and copy book files into
      any folder on the drive; the device indexes them on disconnect. There is no
      microSD slot, so the 32 GB of internal storage is all you have.

Setting up an InkPad Color 3 is quick. Two optional accounts are worth
understanding: a PocketBook account unlocks the wireless delivery and cloud
features, and an Adobe ID lets the device open DRM-protected library books
directly. The one thing to get right early is your expectation of the colour
screen — it is a genuine colour reader, but a calm, muted one, and plain text
still looks best in its black-and-white mode.
