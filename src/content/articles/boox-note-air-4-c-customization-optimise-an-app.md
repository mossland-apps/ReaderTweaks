steps:
  - instruction: Open the optimisation dialog for an app
    detail: >-
      From the Apps screen, long-press an app and choose "Optimise" (or open the
      app, then swipe down for the control centre and tap the optimisation icon).
      A panel of sliders and toggles appears, applying only to that app.
  - instruction: Set the refresh mode
    detail: >-
      Text readers get HD or Regal; browsers, comics and stores get Balanced or
      Fast. This overrides the global mode whenever the app is in front.
  - instruction: Choose colour or black-and-white
    detail: >-
      For a plain text reader, set black-and-white — it is sharper and refreshes
      cleaner. For a comic, magazine, maps or photo app, keep colour on. This
      toggle is per app, so your Kindle app can be black-and-white while Komikku
      stays colour.
  - instruction: Set full refresh frequency
    detail: >-
      "Full refresh every N pages" clears accumulated ghosting. Every 1 page is
      cleanest but flickers most; every 3 to 5 is a common compromise. For an app
      that manages its own refresh (KOReader), turn this off.
  - instruction: Adjust contrast, bleach and sharpen
    detail: >-
      "Enhance contrast" or "bleach whites" fixes grey-looking text and faint UI.
      Use it sparingly — too much crushes thin fonts. "Sharpen" or "bold text"
      helps small type. Colour content generally needs less of this.
  - instruction: Change the app's DPI if the layout is cramped or huge
    detail: >-
      Some phone apps show a tiny layout or an oversized one on the 10.3-inch
      screen. The DPI slider rescales the app — nudge it until buttons and text
      are comfortable, then reopen the app to apply.
  - instruction: Filter animations and handle dark themes
    detail: >-
      Turn on "animation filter" for almost every reading and store app to stop
      fades and page-curl stutter. If an app forces a dark theme, use the "force
      light" or colour-invert option so text is dark-on-light.

The optimisation dialog is where a BOOX goes from "usable" to "good". On the
Note Air 4 C there is one extra lever — the per-app colour toggle. Set text
readers to black-and-white and HD, keep colour on for comics and magazines, set
full-refresh frequency (off for KOReader), nudge contrast only if text is grey,
fix the DPI if the layout is wrong, and filter animations. Ten minutes per app.
