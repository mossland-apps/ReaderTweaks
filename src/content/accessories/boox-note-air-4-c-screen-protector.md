A genuine trade-off. If you write for long stretches, the added tooth makes the
pen more pleasant and controlled. In exchange, reading text looks a little less
crisp, the already-muted colour looks slightly duller, and pen tips wear out
sooner. If you mostly read and write only occasionally, a plain smooth protector
or none at all is the better choice — the bare screen is already matte.
