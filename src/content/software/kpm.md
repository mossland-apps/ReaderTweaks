name: KPM (Kindle Package Manager)
kind: tool
parent: koreader
summary: An on-device package manager bundled with modern Kindle jailbreaks. It downloads and installs Kindle homebrew, including KOReader, from a search-bar command.
aliases:
  - kindle package manager
  - kpm
homepage: https://kindlemodding.org/kindle-dev/kpm/
---

KPM replaced the KUAL and manual-copy method as the recommended way to install
KOReader on a jailbroken Kindle, from firmware 5.19.4 onward. You type commands
such as `;kpm update` and `;kpm install koreader` into the Kindle's search bar;
KPM fetches the package and adds a launcher scriptlet to the home screen. It is
still marked experimental, and older non-touch Kindles use the legacy KUAL
method instead.
